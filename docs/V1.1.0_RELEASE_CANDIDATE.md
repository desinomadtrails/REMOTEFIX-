## 4. Security Audit & Controls

- **JWT Secret Guard**: Startup function `validateJwtSecret()` checks `JWT_SECRET`. Throws critical error if missing or under 32 characters in `NODE_ENV=production`.
- **CORS Resolution**: Function `resolveCorsOrigin()` restricts origin headers based on `CORS_ALLOWED_ORIGINS` in production and permits `localhost` in development.
- **Security Headers**: Hono `securityHeaders` middleware applies strict CSP, HSTS, X-Content-Type-Options, Frame-Ancestors `none`, and anti-clickjacking headers.
- **Rate Limiting**: `apiRateLimiter` (150 req/min) and `authRateLimiter` (10 req/min) active across endpoints.

---

## 5. Performance Audit & Metrics

- **Response Payload Compression**: Response payload compression active via `hono/compress`.
- **Bundle Footprint**: `apps/web` index bundle size 44.35 kB (Gzip 10.26 kB); React vendor bundle 231.38 kB (Gzip 73.97 kB).
- **Docker Layer Caching**: `Dockerfile` copies package manifests (`packages/*/package.json`, `apps/*/package.json`) prior to `npm ci`, yielding 4.0s cached container build times.
- **Database Cold-Start**: Warmup middleware ensures pool connections are established before processing API requests.

## 7. Deployment & Rollback Plan

### Deployment Checklist
1. Verify `develop` branch pipeline status on GitHub Actions (`30991971559` passed).
2. Tag release candidate: `git tag -a v1.1.0-rc1 -m "Release Candidate v1.1.0-rc1"`.
3. Push tag: `git push origin v1.1.0-rc1`.
4. Deploy container image: `docker compose build && docker compose up -d`.
5. Verify health check probes: `curl http://localhost:8787/health/liveness`.

### Rollback Plan
1. If production deployment fails, revert to previous stable tag `v1.0.2`: `git checkout v1.0.2`.
2. Redeploy container image: `docker compose up -d --build`.
3. In Azure App Service, invoke deployment slot swap / instant rollback to previous slot deployment.
