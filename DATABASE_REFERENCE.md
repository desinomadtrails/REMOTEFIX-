## 1. Schema Overview & Relational Map

The database contains 28 normalized tables managing multi-tenant enterprise data.

```
organizations (Tenant)
  ├── departments (1:N)
  ├── users (1:N)
  │     ├── roles (N:1)
  │     └── bookings (1:N)
  ├── assets (1:N)
  └── audit_logs (1:N)
```

---

## 2. Core Relational Tables

### 2.1 `organizations`
- `id` (`varchar(36)`, Primary Key)
- `name` (`varchar(255)`, `notNull`)
- `slug` (`varchar(100)`, `unique`, Indexed)
- `tier` (`varchar(50)`, default `'enterprise'`)
- `status` (`varchar(20)`, default `'active'`, Indexed)

### 2.2 `users`
- `id` (`varchar(36)`, Primary Key)
- `organizationId` (`varchar(36)`, Foreign Key -> `organizations.id`)
- `email` (`varchar(255)`, `notNull`, `unique`, Indexed)
- `passwordHash` (`varchar(255)`, `notNull`)
- `role` (`varchar(50)`, default `'customer'`, Indexed)

### 2.3 `bookings` (FSM Work Orders)
- `id` (`varchar(36)`, Primary Key)
- `customerId` (`varchar(36)`, Foreign Key -> `users.id`)
- `engineerId` (`varchar(36)`, Foreign Key -> `users.id`)
- `status` (`varchar(30)`, default `'pending'`, Indexed)
- `serviceType` (`varchar(100)`, `notNull`)
- `scheduledAt` (`datetime2`, `notNull`)

### 2.4 `assets` (ITAM)
- `id` (`varchar(36)`, Primary Key)
- `organizationId` (`varchar(36)`, Foreign Key -> `organizations.id`)
- `assetTag` (`varchar(100)`, `notNull`, `unique`, Indexed)
- `name` (`varchar(255)`, `notNull`)
- `type` (`varchar(50)`, `notNull`, Indexed)

## 3. Database Indexes & Foreign Keys

- **Foreign Key Coverage**: 100% of child table foreign keys contain corresponding non-clustered indexes (e.g. `idx_depts_org_id`, `idx_roles_org_id`, `idx_assets_org_id`).
- **Parameterized Statements**: 100% of queries execute via prepared T-SQL statements generated by Drizzle ORM.
