# RemoteFix Workflow Standards Skill

## Purpose
Govern execution pipeline to guarantee high reliability of code adjustments.

## Scope
Implementation plans, verification scripts, and walk-through reports.

## Responsibilities
- Create detailed plans before code modifications.
- Complete walkthrough documentation.

## Decision Rules
- **Rule**: Any change affecting database schemas requires database test run.

## Best Practices
- Refer to [workflows.md](file:///e:/SURAJ/REMOTEFIX-/.agents/knowledge/workflows.md).
- Log test execution output directly into walk-through files.

## Common Mistakes
- Modifying project files without establishing a task list in `task.md`.

## Completion Checklist
- `[ ]` walkthrough file details execution results.
