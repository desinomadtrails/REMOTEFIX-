# Playbook: Implementing a New UI Component

## Goal
Create a reusable React UI component.

## Prerequisites
- Visual designs approved.

## Steps
1. Add component file under `packages/ui/src/components/` or local app views.
2. Define component props typescript interfaces.
3. Apply Tailwind CSS v4 aurora and glow classes.
4. Export component from index libraries.

## Verification
- Compile code and verify layout in browser using Playwright.

## Rollback
- Revert file creations.

## Definition of Done
- Component compiles cleanly and renders on target pages.
