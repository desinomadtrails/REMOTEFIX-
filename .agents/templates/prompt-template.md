# Prompt Template - RemoteFix

## Purpose
Standardizes AI system instructions blueprints.

## When to use
When introducing role-specific system prompts.

## Required inputs
- Context boundaries.

## Example
```markdown
# Role: Database Specialist
## Objective
Verify clustered primary keys.
## Constraints
Only mssql tables are valid.
```

## Common mistakes
- Omitting XML wrapper indicators.

## Checklist
- [ ] Prompt includes role definitions.
