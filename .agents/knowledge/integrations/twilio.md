# Twilio SMS Integration - RemoteFix

## Purpose
Send SMS dispatches to field engineers for urgent bookings.

## Scope
Applies to notifications triggered by dispatcher assignments.

## Overview
Twilio SMS ensures engineers receive immediate alerts for on-site dispatches.

## Standards
- Send SMS alerts only when booking priorities are set to `high` or `urgent`.

## Examples
*Dispatch trigger SMS parameters:*
- Target number, priority flag, and booking reference text.
