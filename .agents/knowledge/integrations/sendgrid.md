# SendGrid Email Integration - RemoteFix

## Purpose
Send transactional emails for booking confirmations, engineer assignments, and payment receipts.

## Scope
Applies to the notification engine in `@remotefix/utils`.

## Overview
SendGrid handles transactional communications triggered by status updates in the system.

## Standards
- Configure Sender Authentication and SPF/DKIM records.
- Retrieve API keys from secure environment variables.

- Invoke `@remotefix/utils` email client with custom templates configuration parameters.
