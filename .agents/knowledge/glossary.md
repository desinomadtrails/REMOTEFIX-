# Platform Glossary - RemoteFix

## Purpose
Provides definitions for concepts and terms used across the RemoteFix platform.

## Scope

## Overview

## Standards

## Examples
*Glossary definitions:*
- **AMC**: Annual Maintenance Contract.
- **SLA Threshold**: Target response or resolution buffer times.
- **PoW (Proof of Work)**: Base64 image and description uploaded by engineers upon completing dispatches.
- **Aurora Glow**: Design tokens representing Tailwind v4 theme colors.
