# Commit Enforceable Standards
- Format all commit logs using conventional commit rules:
  - `feat(<component>): <message>`
  - `fix(<component>): <message>`
  - `chore(<component>): <message>`
  - `docs(<component>): <message>`
  - `refactor(<component>): <message>`
  - `perf(<component>): <message>`
  - `test(<component>): <message>`
- Keep commit titles under 72 characters.
