# Naming Enforceable Standards
- React components and files must use PascalCase (e.g. `BookingForm.tsx`).
- React custom hooks must use camelCase starting with "use" (e.g. `useAuth.ts`).
- Directory names must use kebab-case (e.g. `audit-logs/`).
- Variables, functions, and file paths must use camelCase.
- Environment variables must use UPPER_SNAKE_CASE (e.g. `DATABASE_URL`).
